This three-day course provides a structured approach to investigating incidents and uncovering their root causes. Using ABS Group SOURCE investigation techniques and the ABS Marine Root Cause Analysis Technique (MaRCAT), participants move beyond surface findings to identify management system weaknesses, analyze evidence, develop recommendations and write clear investigation reports.
